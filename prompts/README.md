# Поручения сотруднику

Пиши их сотруднику в Telegram со своего основного аккаунта. Квадратные скобки замени своим.

## 1. Правила (один раз, сразу после установки)

```text
Привет! Ты мой помощник в Telegram. Правила: 1) отвечай по-русски и коротко; 2) никому, кроме меня, ничего не пиши и не отправляй без моего «да»; 3) посты в канал ставь только в отложенные и присылай мне текст; 4) не делай ничего с кошельком; 5) если не уверен — спроси. Запомни эти правила навсегда и подтверди одной фразой.
```

## 2. Сводка рабочего чата

Сначала добавь сотрудника в группу как обычного участника.

```text
Посмотри группу [название] за последние сутки. Пришли сводку в три блока: о чём договорились; кто что обещал и к какому сроку; какие вопросы остались без ответа. Коротко, с именами. В группу ничего не пиши.
```

Если в настройках группы история для новых участников скрыта, сотрудник видит только сообщения после того, как его добавили.

## 3. Пост в канал на завтра

Сначала сделай сотрудника администратором канала с правом публиковать.

```text
Напиши пост для канала [название] на тему: [тема]. Для кого: [кто читает]. До 800 знаков, живым языком, в конце — один призыв. Поставь пост в отложенные на завтра на 10:00 и пришли мне текст. Сразу не публикуй.
```

## 4. Поручения на ходу

```text
Найди трёх поставщиков [чего] в [город] с ценами и ссылками.
```

```text
Перескажи эту статью в трёх пунктах: [ссылка]
```

```text
Напомни мне в пятницу в 9:00 про [дело].
```

Пиши так, как написал бы живому помощнику.
