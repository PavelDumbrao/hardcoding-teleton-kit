# PROMPT · установка ИИ-сотрудника в Telegram (Teleton) одним сообщением

Ученику достаточно отправить своему агенту (Claude или Codex в приложении, новая пустая папка) одну фразу:

```text
Установи мне ИИ-сотрудника для Telegram по инструкции: https://github.com/PavelDumbrao/hardcoding-teleton-kit/blob/main/PROMPT.md
Я не программист: все команды выполняй сам и веди меня по-русски.
```

Агент читает этот файл и выполняет блок ниже.

---

```text
Ты мой агент на компьютере. Поставь мне ИИ-сотрудника для Telegram — программу Teleton (официальный репозиторий https://github.com/TONresistor/teleton-agent) — и докажи, что он работает.

Я не программист. Всю техническую работу делай сам. Мне оставляй только то, что могу сделать только я: ввести ключи и коды в окне мастера и отсканировать QR-код телефоном.

ПРАВИЛА
1. Ключи, коды из Telegram, облачный пароль и фразу кошелька (24 слова) в чат не проси. Я ввожу их сам в окне мастера в браузере.
2. Сотрудник живёт во ВТОРОМ аккаунте Telegram (своя вторая SIM или eSIM). Мой основной аккаунт в мастер не вводим: на сообщения со своего же аккаунта Teleton не отвечает.
3. Перед каждым действием, которое что-то ставит или меняет, одной фразой скажи, что сделаешь. Опасных и необратимых действий без моего «да» не делай.
4. Не говори «готово» без доказательства: сотрудник ответил «Pong» на /ping с моего основного аккаунта.

ШАГ 1 · Проверь, что у меня всё под рукой. Спроси одним сообщением и дождись ответа:
- второй аккаунт Telegram на своей второй SIM или eSIM (на телефоне: «Настройки» → «Добавить аккаунт»);
- api_id и api_hash с my.telegram.org (урок 1.З.1 курса);
- мой числовой ID — его пришлёт бот @userinfobot, если написать ему с основного аккаунта;
- ключ OpenRouter (openrouter.ai → Keys; оплата зарубежной картой, пополнения на 5 долларов хватит надолго);
- бесплатный ключ Tavily для поиска в интернете (tavily.com, регистрация по почте) — можно пропустить, тогда сотрудник не будет искать в интернете.
Чего-то нет — подскажи по-простому, где взять, и подожди.

ШАГ 2 · Node.js. Нужна версия 22.22 и новее (подходит 24 LTS). Проверь `node -v`.
- Нет или старая: Windows — поставь `winget install OpenJS.NodeJS.LTS`; Mac — через Homebrew (`brew install node`), а если Homebrew нет — скачай установщик LTS с nodejs.org и попроси меня его запустить. После установки открой новое окно терминала и снова проверь `node -v`.

ШАГ 3 · Поставь Teleton: `npm install -g teleton@latest`. Проверь `teleton --version`.
- Обрыв связи при установке (ECONNRESET, ETIMEDOUT) — просто повтори команду, обычно встаёт со 2–3 попытки.

ШАГ 4 · Открой мастер настройки в браузере: `teleton setup --ui` (окно http://localhost:7777/setup). Команду запусти так, чтобы она продолжала работать, пока я прохожу мастер.

ШАГ 5 · Веди меня по шести экранам мастера по-русски, по одному экрану:
1. Welcome — имя сотрудника (любое, например «Лиза»), Telegram Mode — User Account, галочка «I understand the risks…», кнопка «Next: Provider».
2. Provider — карточка OpenRouter, в поле API Key я вставлю ключ сам. В списке Model выбери DeepSeek V4.1 Flash (deepseek/deepseek-v4.1-flash). Модель по умолчанию НЕ оставляй: она примерно в 100 раз дороже.
3. Config — Admin User ID: мой числовой ID от @userinfobot. DM Policy — Admin Only. Group Policy — Admin Only. Require @mention in groups — включить. Coding Agent — Off. В блоке Optional API Keys в поле Web Search я вставлю ключ Tavily сам (или пропускаю). Остальные ключи (Bot Token, TonAPI, TonCenter) не нужны.
4. Wallet — это шаг мастера Teleton, кошелёк нам не нужен. Нажми «Generate Wallet», отметь «I have saved my recovery phrase» и иди дальше. Фразу я при желании перепишу на бумагу. Деньги на кошелёк не кладём, никому фразу не показываем.
5. Telegram — API ID и API Hash вставляю я; Login method — QR Code.
6. Connect — на экране появится QR-код. Скажи мне: на телефоне ВТОРОГО аккаунта открыть «Настройки» → «Устройства» → «Подключить устройство» и навести камеру на QR. Код живёт около полуминуты: не успел — пусть нажмёт обновить. Если у второго аккаунта стоит облачный пароль, мастер спросит его — ввожу я.
После последнего экрана нажми «Start Agent» (сотрудник запустится сам).

ШАГ 6 · Правила сотрудника. Скачай из репозитория https://github.com/PavelDumbrao/hardcoding-teleton-kit файл rules/SOUL-ru.md и допиши его текст в конец файла ~/.teleton/workspace/SOUL.md (сначала сделай копию SOUL.md рядом: SOUL.md.bak). Покажи мне, что дописал. Потом перезапусти сотрудника, чтобы он прочитал правила.

ШАГ 7 · Ярлык запуска. Скачай из того же репозитория:
- Windows — scripts/start-teleton.cmd, положи на рабочий стол под именем «Сотрудник Telegram.cmd»;
- Mac — scripts/start-teleton.command, положи на рабочий стол под именем «Сотрудник Telegram.command» и сделай исполняемым (chmod +x).
Объясни мне: двойной клик — сотрудник запущен и работает, пока открыто это окно и включён компьютер; закрыть окно — сотрудник остановлен.

ШАГ 8 · Проверка. Попроси меня написать сотруднику со своего ОСНОВНОГО аккаунта: /ping. Готово, когда он ответил «Pong». Не ответил — проверь по порядку: я пишу не с аккаунта сотрудника; Admin User ID — мой ID; DM Policy — Admin Only; окно сотрудника открыто. Найди причину сам и почини.

ШАГ 9 · Итог мне коротко:
- где ярлык и как остановить сотрудника;
- где смотреть расходы: openrouter.ai → Activity;
- как отключить совсем: на телефоне второго аккаунта «Настройки» → «Устройства» → завершить сеанс сотрудника;
- первые поручения сотруднику — в файле prompts/ этого репозитория (правила, сводка чата, пост на завтра, поручения на ходу).
```
