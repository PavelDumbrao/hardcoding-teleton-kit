# ИИ-сотрудник в Telegram · набор курса Хардкодинг PRO

Сотрудник со своим аккаунтом в Telegram. Ты добавляешь его в рабочие чаты и канал, пишешь ему с телефона, а он:

- присылает сводку рабочего чата: о чём договорились, кто что обещал, что повисло;
- пишет посты и ставит их в отложенные канала;
- ищет в интернете, пересказывает статьи, напоминает о делах.

В основе — бесплатная программа [Teleton](https://github.com/TONresistor/teleton-agent) с открытым кодом. Этот набор — инструкция для твоего агента, правила сотрудника, готовые поручения и ярлык запуска. Урок курса: 1.З.4 «ИИ-сотрудник в твоём Telegram».

## Как поставить

Открой своего агента (Claude или Codex в приложении) в новой пустой папке и отправь:

```text
Установи мне ИИ-сотрудника для Telegram по инструкции: https://github.com/PavelDumbrao/hardcoding-teleton-kit/blob/main/PROMPT.md
Я не программист: все команды выполняй сам и веди меня по-русски.
```

Агент сам поставит Node.js и Teleton, откроет мастер настройки в браузере и проведёт тебя по шести экранам. Ты только вводишь ключи и сканируешь QR-код. Подробно, что делает агент: [PROMPT.md](PROMPT.md).

## Что приготовить

| Что | Где взять |
|---|---|
| Второй аккаунт Telegram | своя вторая SIM или eSIM; на телефоне «Настройки» → «Добавить аккаунт» |
| api_id и api_hash | my.telegram.org, урок 1.З.1 |
| Свой числовой ID | напиши боту @userinfobot со своего основного аккаунта |
| Ключ OpenRouter | openrouter.ai → Keys; оплата зарубежной картой, пополнения на 5 долларов хватит надолго |
| Ключ Tavily (по желанию) | tavily.com, бесплатно 1000 запросов в месяц — для поиска в интернете |

Почему второй аккаунт: на сообщения со своего же аккаунта Teleton не отвечает. Сотрудник — как новый человек в команде: свой номер, ты добавляешь его, куда нужно, и командуешь со своего аккаунта.

## Мастер настройки: что выбрать

1. **Welcome** — имя сотрудника, режим User Account, галочка.
2. **Provider** — OpenRouter, твой ключ, модель **DeepSeek V4.1 Flash**. Модель по умолчанию не оставляй: она примерно в 100 раз дороже.
3. **Config** — Admin User ID = твой ID; DM Policy и Group Policy — **Admin Only**; Require @mention in groups — включено; ключ Tavily.
4. **Wallet** — шаг мастера, кошелёк нам не нужен: Generate Wallet, галочка, дальше. Деньги туда не кладём.
5. **Telegram** — api_id, api_hash, вход по QR Code.
6. **Connect** — на телефоне второго аккаунта «Настройки» → «Устройства» → «Подключить устройство», наведи камеру на QR.

## Первые поручения

Готовые тексты — в [prompts/README.md](prompts/README.md): правила, сводка рабочего чата, пост на завтра, поручения на ходу. Правила сотрудника агент дописывает в его системные правила при установке: [rules/SOUL-ru.md](rules/SOUL-ru.md).

## Запуск, остановка, расходы

- **Запуск:** ярлык «Сотрудник Telegram» на рабочем столе. Сотрудник работает, пока открыто его окно и включён компьютер.
- **Остановка:** закрой окно.
- **Отключить совсем:** на телефоне второго аккаунта «Настройки» → «Устройства» → завершить сеанс сотрудника.
- **Расходы:** openrouter.ai → Activity. На дешёвой модели обычный день поручений стоит центы.
- **Круглосуточно:** перенос на сервер — урок 2.Б.4 «Агент на сервере 24/7».

## Если не получилось

| Что случилось | Что сделать |
|---|---|
| Сотрудник молчит | Пиши со своего основного аккаунта; в Admin User ID должен стоять твой ID |
| QR-код не сработал | Он живёт около полуминуты: нажми обновить и сканируй сразу |
| Медленно и дорого | Проверь модель: не осталась ли дорогая по умолчанию |
| В сводке нет старых сообщений | В группе скрыта история для новых участников — сотрудник видит только новое |
| Ошибка при установке | Скопируй текст ошибки (ключи сотри) и отдай агенту, который ставил: он починит |

## Безопасность

- Ключи и коды вводишь только в окне мастера, в чат агенту не отправляешь.
- Сотрудник слушается только тебя (Admin Only), в группах — только по упоминанию.
- Посты — только в отложенные: ты видишь текст до публикации.
- Фразу кошелька никому не показывай, деньги на кошелёк не клади.
